A NexGen Accounting AI

A aplicação precisa do servidor local

O ficheiro foi aberto diretamente pelo Windows. Uma aplicação moderna não consegue funcionar corretamente através de um endereço file://.

Abra o NexGen Accounting AI em dois cliques

Execute Abrir NexGen Accounting AI.cmd na pasta principal. Em alternativa, use este comando no PowerShell:

powershell -NoProfile -ExecutionPolicy Bypass -File "C:\NexGen Accounting AI\scripts\start-local.ps1"Abrir aplicação local

Se o endereço ainda não responder, execute primeiro o lançador indicado acima.
